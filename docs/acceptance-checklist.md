# 实机验收清单（Release Acceptance Checklist）

每次发布前在真实 Windows/macOS 机器上逐项勾选。代码修复不能替代实机验收（WebView2 冷启动、
mixed DPI、真实 Word COM 行为只有实机能覆盖）。勾选后在本文件末尾追加一行记录（日期/机器/版本）。

## 环境矩阵

| 项目        | 待测                                       |
| ----------- | ------------------------------------------ |
| Word 版本   | 2016 / 2019 / 2021 / Microsoft 365         |
| Office 位数 | 32 位 / 64 位                              |
| 显示缩放    | 100% / 125% / 150% / 200%                  |
| 多屏        | 双屏 mixed DPI（如 100% + 200%）           |
| OS          | Windows 10 / 11；macOS（如果测 Office.js） |

## A. 公式插入（Word）

- [ ] 行内公式插入：光标处插入，与正文基线对齐
- [ ] 行间（display）公式插入：居中显示，间距合理
- [ ] 编号公式插入：`(1)` 正常显示，STYLEREF 章节编号 `(2.1)` 正确
- [ ] 编号公式在 100% / 125% / 150% / 200% 缩放下编号不错位
- [ ] OLE 模式插入后双击可再次编辑，修改后保存回文档
- [ ] 图片（image）模式插入：Word/PowerPoint/画图中粘贴为图片
- [ ] 文档另存为 .docx 后重新打开，公式与编号不丢失

## B. 交叉引用与公式目录（新增）

- [ ] 以「编号」模式插入公式后，点「交叉引用」→ 选公式 → 光标处出现 `(1)` 或 `(2.3)`
- [ ] 按 F9 刷新后引用编号与公式编号一致；编号变化后刷新同步更新
- [ ] Ctrl+点击交叉引用可跳转到对应公式（`\h` 超链接）
- [ ] 对非编号公式插入交叉引用 → 前端显示友好错误（BOOKMARK_NOT_FOUND），Word 无残留
- [ ] 「公式目录」在光标处插入列表，F9 刷新后列出全部编号公式
- [ ] 文档重新打开后目录/引用仍可用
- [ ] 「检查编号」：重复编号 / 跳号 / 无法解析的编号被报告，无问题时提示通过

## B2. AI 生成（新增）

- [ ] 设置中配置 AI endpoint/API key/model 后，输入描述 → 「AI 生成」→ 编辑器出现 LaTeX
- [ ] 生成结果可编辑，随后复制 / 插入正常
- [ ] 未配置 API key 时提示到设置配置；AI 返回空/错误时有友好提示
- [ ] 生成失败时按钮恢复可用，无残留 loading 态

## C. OLE 裁切与渲染（上次修复的核心）

- [ ] 长公式（积分上下限、矩阵、分段函数）OLE 外框不裁切文字
- [ ] 斜体 overhang / 积分号 / accent / 右上标 / rule endpoints 不贴边
- [ ] 100% / 125% / 150% / 200% 缩放 + 双屏 mixed DPI 下均完整
- [ ] 行内公式上下不超高、不压行

## D. 截图识别

- [ ] 单屏截图 → 识别 → 结果正确
- [ ] 多屏（含不同 DPI 显示器）截图：内容完整、无 `missing=capture-xxx` 超时
- [ ] WebView2 冷启动后立即截图不超时
- [ ] 识别期间新任务不覆盖旧任务结果（多任务覆盖）

## E. 剪贴板（跨平台）

- [ ] Windows：Ctrl+C Smart → 剪贴板含 LaTeX/Markdown/HTML/MathML/OMML/SVG/PNG/JSON 多格式
- [ ] Windows：粘贴到 Word 得到公式（OMML 或图片），粘贴到画图得到透明 PNG
- [ ] Windows：PNG 以 CF_DIBV5/CF_DIB 写入，PowerPoint 可粘贴
- [ ] macOS/Linux：显式「复制 MathML」「复制 OMML」不失败，剪贴板含真实标记内容
- [ ] macOS/Linux：显式「复制 SVG」→ 剪贴板含图片；Smart 复制含 LaTeX + 图片

## F. 公式库与识别

- [ ] 搜索支持子串/拼音/别名，结果按 置顶>收藏>次数>最近 排序
- [ ] 收藏/置顶/停用/隐藏在重启后保持
- [ ] 图片/PDF/截图识别任务并行不互相覆盖

## G. 安装与卸载

- [ ] MSI / NSIS 全新安装后 VSTO 可加载，OLE 组件注册成功
- [ ] RecognitionQuality 基线哈希校验通过（无 HASH_MISMATCH）
- [ ] 卸载后无残留服务/注册表项
