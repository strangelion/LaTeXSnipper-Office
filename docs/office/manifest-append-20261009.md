# Word 原生批次增量清单

更新：2026-10-09。只覆盖新插入的原生行内公式，不是所有格式、所有宿主或安装版验收。

该实验路线默认关闭：当前配对实测未达到性能要求。生产批次继续使用已有清单路径；
“试点通过”不能解释为已默认部署或整体批量转换提速。

## 实现边界

批次会话只绑定一个 Word 文档和调用线程。新公式保留独立 ID；每项直接追加自己的
清单条目，并从当前关联的清单回读完整条目，确认后执行器才删除原 LaTeX。
不读取/解析/重建整份清单，也不延后到批末一次写入。原有条目和未知扩展保持不变。
旧的单项更新、图片/OLE 插入和其他宿主清单路径未由此整体替换。

重复清单、错误根节点、会话中的 part 身份变化或任何已有同 ID 条目均拒绝。
回读不一致/追加执行状态不明确会阻止该会话后续写入；只清除本会话创建且仍与
快照一致的条目，不删除后续被修改或身份不明确的数据。不能证明清理成功时保留
诊断和原文，不能宣称任意外部修改都可以恢复。

会话最多 10,000 次追加尝试、16 MiB 累计新条目 UTF-8；每项最多 2 Mi 字符。
回读禁用 DTD/外部 XML 实体，最大深度 64。预算失败不删除原文；调用方可分批处理。
这不是 10,000 项真实文档性能或数学准确率验收。

## 验证范围

共享故障测试覆盖追加前/后异常、回读差异、DTD、独立 ID、文档/线程隔离、
预算、已变条目的清理保护和 dispose 不删除已提交数据。真实 x64 Word 覆盖
重复 part、错误根节点、part 替换、未知扩展 ID 冲突、扩展保留及保存重开。

专用 HostTests 模式保持 Word 应用隐藏，并检测 OS 窗口没有显示。Word `InsertXML`
需要可操作的内部文档窗口；扫描/执行器因此支持内部显式 Document 绑定，
并不据此宣称加载项已经可以任意控制其他实例或文档。

复现入口：`--manifest-safety`、`--batch-manifest 250`、`--batch-manifest-legacy 250`。
输入为 `apps/native-office/LaTeXSnipper.Word.HostTests/fixtures/word-manifest-append-v1.json`；
先构建 `LaTeXSnipper.Word.HostTests`，然后传入独立证据目录。共享故障测试可用
`LaTeXSnipper.Shared.Tests.exe --manifest-append` 单独运行。

## 配对实测

Windows x64、Core i5-13500H、Word `16.0.18526.20672`，Release。两轮交替顺序，
每条路线每轮都是新文档：250 项同一 `x^2`，四种数学定界符交替，一项注入无效 OMML，
每批 25 项。两侧都启用重复 OMML 模板与 Range 插入，只改变清单路线。
没有独立丢弃的预热轮，每条路线仅两次测量，不能当成稳定分布。

| 路线 | 第一轮执行 (s) | 第二轮执行 (s) | 平均执行 (s) | 平均清单阶段 (s) |
| --- | ---: | ---: | ---: | ---: |
| 旧整份清单写入 | 55.947 | 60.439 | 58.193 | 7.515 |
| 逐条追加及回读 | 76.741 | 63.317 | 70.029 | 9.954 |

执行取各批计时之和，不含扫描、保存重开和最终核对，也不含 Core 转换或桌面管道。
阶段是嵌套的，不能相加。当前追加路线平均执行慢约 **20.3%**，不宣称提速；
减少整份 XML 传递没有抵消 DOM 身份检查和新增回读开销。

四次均为 249 项成功、1 项原文保留、0 项执行失败；相邻正文、独立 ID、完整 payload、
清单与内容控件数量、保存重开和剪贴板核对通过。这不是数学等价、视觉保真、
安装版端到端耗时或 Word 原生转换基线。[测量快照](manifest-append-measurements-20261009.json)
记录原始 JSON 摘要、测量构建的产物 SHA-256 和默认门禁；测量后只补默认关闭及安全 harness 的显式参数。

保留 DOCX、完整各批 JSON 和安全记录。默认关闭后安全与构建检查再次通过；
