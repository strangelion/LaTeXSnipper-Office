# Word 批量转换与快速更新后续计划（O-06）

更新：2026-10-03。此文记录待实现工作，不代表已完成性能优化。

## 当前可复用基础

- LaTeXSnipper 原生公式使用内容控件标记 `latexsnipper:formula:<id>`。
- 文档级 CustomXML 清单保存 ID、revision、LaTeX、显示模式、完整 payload 和 OMML/hash。
- 2026-10-03 真实宿主专项覆盖正文、独立页眉/页脚、第二节首页页眉和文本框；
  七个公式及源信息、ID 在保存重开后仍保留。详见 `real-host-acceptance.md`。
- 本轮 250 条重复积分回归：249 转换、1 故意无效项保留、0 执行失败；
  总耗时 328.093 秒，25 条/批 18.136–48.795 秒。不是多样语料准确率，
  也不是速度提升结果。

## 下一轮顺序与验收条件

### 1. 无分隔符 LaTeX（尚未实现）

- [ ] 明确的“将选区作为 LaTeX”命令；原文无需 `$`/`$$`，先预览再确认。
- [ ] 保留显式分隔符扫描作为默认模式；裸命令的全文候选模式必须单独启用。
- [ ] 全文候选展示原文、所在位置、置信度和排除原因，不自动改写普通正文。
- [ ] 覆盖 `\frac{a}{b}`、上下标、环境、多行选区、代码/路径、普通文字、
  不完整命令、未知自定义宏及重复公式；拒绝项保持原文和格式。
- [ ] 同步 COM 与 Office.js 按钮/帮助及能力限制，不能只有桌面入口。

### 2. 预处理索引和增量更新（尚未实现）

- [ ] 优先按已有公式 ID + revision + OMML/源哈希定位；故事坐标仅作为会话提示。
- [ ] 打开文档只读核对索引：不存在、重复 ID、手动改动、故事迁移需重新扫描。
- [ ] 索引不能依赖长期缓存的字符位置；正文、分节页眉/页脚、文本框分别核对。
- [ ] 缓存键覆盖规范化 LaTeX、宏/符号定义、字体/样式、渲染及转换版本。
- [ ] 未改变的公式跳过转换；修改字体/样式可只更新展示，但保持原始源和编辑能力。
- [ ] 对没有 LaTeXSnipper 元数据的原生 Word 公式，仅保留其 OMML；
  不声称能无损恢复作者原始 LaTeX。
- [ ] 更新预览列出数量、变化项、失败项；用户确认后执行，支持取消和部分完成报告。

### 3. 减少 COM 和重复清单写入（尚未实现）

- [ ] 分阶段计时：扫描、Core 转换/缓存、Word scratch、读回校验、
  元数据读写、字段更新和保存，先确定实际耗时占比。
- [ ] 可恢复的批处理作用域暂停屏幕刷新，结束/异常均恢复原状态。
- [ ] 每批读取清单一次，只对成功项集中提交；提交失败不能删除已有清单或虚报源可回读。
- [ ] 模板/scratch 复用必须保持跨故事定位及读回安全，不能用性能目标取消校验。
- [ ] 结束后集中更新 `SEQ/REF/PAGEREF`，仍要验证陈旧到刷新及保存重开。
- [ ] 对照同机同 Word 的冷/热运行；记录总时间、P95、内存、成功/保留数量。
  至少覆盖 25、250、1,000 条，再进入 10,000 条多样矩阵。

### 4. 可选 DOCX 离线快路径（需单独设计和确认）

- [ ] 仅处理用户指定的已保存副本；不能覆盖打开中的未保存文档。
- [ ] 使用 OOXML 批量修改、备份、临时文件及原子替换；保留关系、样式、
  内容控件、清单、域及交叉引用。
- [ ] 重新打开 Word 做 OMML、位置、版式及回读校验，失败回退到受控 COM 路径。
- [ ] 列出修订、保护、签名、链接及其他不支持情形，不承诺所有 DOCX 均可离线处理。
